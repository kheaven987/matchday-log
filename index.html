Services

Backup

If saving is acting up, export a copy now and again — it downloads a file independent of the app's storage, so you can restore from it if needed.

Report recipient

Who "📋 Generate summary" (on the Fixtures tab) addresses its plain-text mail draft to. This app never sends anything itself.

Delete password

Required to delete a logged issue — a light deterrent against accidental deletion, not real security (it's stored in this browser and checked in the page itself). You'll be asked to create one the first time you try to delete something, or set it here.

API-Sports proxy

Only needed when running this app outside claude.ai — browsers block direct calls to API-Sports (CORS), so fixture lookups need a small proxy in between. Deploy the included Cloudflare Worker script and paste its URL here.

Sync across devices

Keeps fixtures, log entries, and clients in sync across your own devices, using the same Cloudflare Worker as the API-Sports proxy (a /sync endpoint on it). Built for one person on multiple devices — if two devices save at the same moment, the most recent one wins.
